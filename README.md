# 더포레 요양병원 · THE FORET

**Type:** Virtual brand / medical website template demo, not a licensed healthcare provider. **Version:** v1.0.0 (2026-11-08).

**Domain target:** `https://fore.lexid.site` · **GitHub:** `skvive/fore`

## Contents
- 7 public static pages: landing, specialty centers, room concepts, illustrative cost estimator, privacy-preserving demo admission flow, health journal, Blogger-like preview.
- AI-generated concept photos and original SVG forest-tree wordmark, favicon, OG image.
- `sitemap.xml`, `robots.txt`, `rss.xml`, SEO tags and WebSite structured data.
- Responsive accessible navigation and offline-capable assets except optional Google Fonts fallback.
- `blogger/` contains **proposed** Blogger copy/template and OAuth-based bridge guide. It does not silently publish to an external Google Blog.

## Run
```sh
python -m http.server 8080
# http://localhost:8080
```
No npm installation required. Static deployment on Vercel: root directory `/` and framework `Other`.

## Medical/safety scope
The fictional facility **does not** have verified beds, operating clinicians, dialysis capability, rehabilitation equipment, insurance contracts, actual prices, or a working 360° capture. Images are entirely synthetic. Site contains no fictitious patient reviews, awards, safety guarantees, or invented contact numbers.

**Do not enter real patient information.** The demo form never submits or stores files or medical data. The estimator uses fictional unit rates and is not an insurance calculator. Before real launch, verify provider registration, equipment, locations, pricing, HIRA/NHIS rules, medical advertising compliance, privacy/security, audit logs, consent, retention, and accessibility.
